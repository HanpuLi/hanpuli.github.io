關於本站

本站刻意保持靜態。公開頁面首先是完整文件：HTML、CSS 與本地資源已經寫好，只有在互動確有作用時才加入少量原生 JavaScript。

原則很簡單：內容不能依賴前端框架、瀏覽器端翻譯層或 JavaScript 渲染才能閱讀。

01

架構

刻意保持靜態。

作品站由小型模板與結構化 JSON 生成完整 HTML5 文件。Python 3 標準函式庫生成器會預先輸出每個語言版本，瀏覽器毋須在執行時拼裝頁面。

網站從 main 分支經 GitHub Pages 發佈。作品站背後沒有 CMS、應用框架、資料庫或伺服器端應用。

執行時
HTML5 · CSS · 原生 JavaScript
建置
Python 3 · JSON · HTML templates
託管
GitHub Pages

02

內容與語言

七個版本，沒有執行時翻譯。

英文、香港繁體中文、簡體中文、日文、德文、法文與俄文均生成為獨立靜態版本，各有 canonical URL、hreflang alternate 與語系 metadata。

文學文本比一般介面文字有更嚴格的規則。指定情況下以繁體中文原文為正；簡體文學版本只做字形轉換並核對來源雜湊，譯文則由專門檢查維持分行與分闋結構。

語系

文學轉換

metadata
canonical · hreflang · Open Graph

03

版式與字體

編輯式 CSS，不用元件框架。

版式使用 CSS Grid、subgrid、container queries、logical properties、custom properties 與流動的 clamp() 尺寸。Media queries 只作保守後備；支援 container queries 的瀏覽器會讓元件依自己的可用寬度重排。

字體全部以 WOFF2 自行託管。拉丁正文主要用 EB Garamond，metadata 用 Courier Prime／Cousine，繁體中文與日文用 Shippori Mincho，簡體中文用 Noto Serif SC，少量香港字形缺口由極小的 I.Ming 子集補齊。CJK 子集以 fontTools 與 Brotli 重建；Noto 來源以 commit 與 SHA-256 固定。

版式
Grid · subgrid · container queries · logical properties
字體
EB Garamond · Courier Prime · Cousine · Shippori Mincho · Noto Serif SC · I.Ming
色彩
light/dark via prefers-color-scheme

04

無障礙

可以調整，但不刪內容。

作品站使用語義 landmark、單一主標題、skip links、清晰的鍵盤 focus、完整語言名稱與足夠大的觸控目標；亦尊重 reduced-motion、higher-contrast 與 forced-colour 等系統偏好。

閱讀面板可切換無襯線字體、放大文字、增加字距行距、縮窄欄寬、簡化版式、減少動態與提高對比。這些都是 progressive enhancement，只在瀏覽器本地保存偏好。

閱讀偏好
sans · larger type · spacing · measure · simple layout · motion · contrast
儲存
只用 localStorage
檢查
自製結構審計 · axe-core 瀏覽器審計

05

圖片與效能

響應式媒體，不靠圖庫程式。

攝影與研究圖版使用 picture/srcset，提供 WebP 與 JPEG 尺寸候選，並明確標示寬高與 responsive sizes。首張圖優先載入，頁面較下方的媒體則 lazy-load 並非同步解碼。

頁面下方區段可使用 content-visibility；View Transitions 與 scroll-linked motion 都只是可選的 progressive enhancement。使用者要求 reduced motion 時會停用動態。

圖片
picture · srcset · WebP · JPEG
載入
explicit dimensions · lazy loading · async decoding
漸進 CSS
content-visibility · View Transitions · scroll timelines

06

建置、QA 與部署

生成結果本身就是可測試的 artefact。

Repository 會檢查生成頁是否最新、各語系 schema 是否一致、文學結構有沒有漂移、無障礙 landmark 與控制項是否完整、本地連結和 fragment 是否有效、圖片是否有 alt text，以及 JavaScript 能否解析。

瀏覽器 QA 另做跨語言與窄／寬 viewport 幾何檢查、axe-core 無障礙掃描與 HTML validation。GitHub Actions 在 push 與 pull request 上重跑輕依賴檢查；GitHub Pages 則獨立從 main 發佈同一批靜態檔案。

repository checks
build freshness · i18n · accessibility · links/assets · JS syntax
browser QA
Playwright · axe-core · html-validate
交付
GitHub Actions · GitHub Pages

07

一個網域，兩類頁面

作品站、詞頁、詩頁、論文外殼、About 頁與 404 頁共享上述多語生成系統。

/mail-assistant/ 下的三份 Cait Mail Assistant 文件是手寫靜態 HTML，配一份小型頁面 CSS；它們沿用作品站的本地無障礙 script，以及自行託管的 EB Garamond／Courier Prime 字體。

瀏覽器執行時的私隱

作品站不載入 analytics、廣告網絡、第三方 web font 或追蹤 script，也不設 cookie。作品站唯一持久的瀏覽器狀態，是本地閱讀偏好記錄。
