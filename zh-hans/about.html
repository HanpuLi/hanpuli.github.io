关于本站

本站刻意保持静态。公开页面首先是完整文档：HTML、CSS 与本地资源已经写好，只有在交互确有作用时才加入少量原生 JavaScript。

原则很简单：内容不能依赖前端框架、浏览器端翻译层或 JavaScript 渲染才能阅读。

01

架构

刻意保持静态。

作品站由小型模板与结构化 JSON 生成完整 HTML5 文档。Python 3 标准库生成器会预先输出每个语言版本，浏览器无需在运行时拼装页面。

网站从 main 分支经 GitHub Pages 发布。作品站背后没有 CMS、应用框架、数据库或服务端应用。

运行时
HTML5 · CSS · 原生 JavaScript
构建
Python 3 · JSON · HTML templates
托管
GitHub Pages

02

内容与语言

七个版本，没有运行时翻译。

英文、香港繁体中文、简体中文、日文、德文、法文与俄文均生成独立静态版本，各有 canonical URL、hreflang alternate 与语系 metadata。

文学文本比一般界面文字有更严格的规则。指定情况下以繁体中文原文为准；简体文学版本只做字形转换并核对来源哈希，译文则由专门检查维持分行与分阕结构。

语系
en-GB · zh-Hant-HK · zh-Hans · ja · de · fr · ru
文学转换
OpenCC helper · source hashes · line-parity checks
metadata
canonical · hreflang · Open Graph

03

版式与字体

编辑式 CSS，不用组件框架。

版式使用 CSS Grid、subgrid、container queries、logical properties、custom properties 与流动的 clamp() 尺寸。Media queries 只作保守后备；支持 container queries 的浏览器会让组件按自己的可用宽度重排。

字体全部以 WOFF2 自行托管。拉丁正文主要用 EB Garamond，metadata 用 Courier Prime／Cousine，繁体中文与日文用 Shippori Mincho，简体中文用 Noto Serif SC，少量香港字形缺口由极小的 I.Ming 子集补齐。CJK 子集以 fontTools 与 Brotli 重建；Noto 来源以 commit 与 SHA-256 固定。

版式
Grid · subgrid · container queries · logical properties
字体
EB Garamond · Courier Prime · Cousine · Shippori Mincho · Noto Serif SC · I.Ming
色彩
light/dark via prefers-color-scheme

04

无障碍

可以调整，但不删内容。

作品站使用语义 landmark、单一主标题、skip links、清晰的键盘 focus、完整语言名称与足够大的触控目标；同时尊重 reduced-motion、higher-contrast 与 forced-colour 等系统偏好。

阅读面板可切换无衬线字体、放大文字、增加字距行距、缩窄栏宽、简化版式、减少动态与提高对比。这些都是 progressive enhancement，只在浏览器本地保存偏好。

阅读偏好
sans · larger type · spacing · measure · simple layout · motion · contrast
存储
只用 localStorage
检查
自制结构审计 · axe-core 浏览器审计

05

图片与性能

响应式媒体，不靠图库程序。

摄影与研究图版使用 picture/srcset，提供 WebP 与 JPEG 尺寸候选，并明确标注宽高与 responsive sizes。首张图优先加载，页面较下方的媒体则 lazy-load 并异步解码。

页面下方区段可使用 content-visibility；View Transitions 与 scroll-linked motion 都只是可选的 progressive enhancement。用户要求 reduced motion 时会停用动态。

图片
picture · srcset · WebP · JPEG
加载
explicit dimensions · lazy loading · async decoding
渐进 CSS
content-visibility · View Transitions · scroll timelines

06

构建、QA 与部署

生成结果本身就是可测试的 artefact。

Repository 会检查生成页是否最新、各语系 schema 是否一致、文学结构有没有漂移、无障碍 landmark 与控件是否完整、本地链接和 fragment 是否有效、图片是否有 alt text，以及 JavaScript 能否解析。

浏览器 QA 另做跨语言与窄／宽 viewport 几何检查、axe-core 无障碍扫描与 HTML validation。GitHub Actions 在 push 与 pull request 上重跑轻依赖检查；GitHub Pages 则独立从 main 发布同一批静态文件。

repository checks
build freshness · i18n · accessibility · links/assets · JS syntax
browser QA
Playwright · axe-core · html-validate
交付
GitHub Actions · GitHub Pages

07

一个域名，两类页面

作品站、词页、诗页、论文外壳、About 页与 404 页共享上述多语言生成系统。

/mail-assistant/ 下的三份 Cait Mail Assistant 文档是手写静态 HTML，配一份小型页面 CSS；它们沿用作品站的本地无障碍 script，以及自行托管的 EB Garamond／Courier Prime 字体。

浏览器运行时的隐私

作品站不加载 analytics、广告网络、第三方 web font 或追踪 script，也不设置 cookie。作品站唯一持久的浏览器状态，是本地阅读偏好记录。
