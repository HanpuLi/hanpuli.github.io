О сайте

Этот сайт намеренно сделан статическим. Публичные страницы прежде всего являются готовыми документами: содержание держится на HTML, CSS и локальных ресурсах, а небольшой объём обычного JavaScript используется только там, где взаимодействие действительно полезно.

Правило простое: содержание должно оставаться читаемым без фреймворка, клиентского слоя перевода и рендеринга через JavaScript.

01

Архитектура

Статика как осознанный выбор.

Портфолио генерируется как полноценные документы HTML5 из небольших шаблонов и структурированного JSON. Генератор на стандартной библиотеке Python 3 заранее выпускает каждую языковую версию; браузеру не приходится собирать сайт во время выполнения.

Сайт публикуется из ветки main через GitHub Pages. За портфолио нет CMS, прикладного фреймворка, базы данных или серверного приложения.

runtime
HTML5 · CSS · обычный JavaScript
build
Python 3 · JSON · HTML templates
хостинг
GitHub Pages

02

Контент и языки

Семь версий, без перевода во время выполнения.

Английская, традиционная китайская (Гонконг), упрощённая китайская, японская, немецкая, французская и русская версии генерируются как отдельные статические издания с canonical URL, hreflang alternates и локализованными метаданными.

Для литературных текстов действуют более строгие правила, чем для обычного интерфейсного текста. Там, где это задано, каноничен традиционный китайский; упрощённые литературные зеркала меняют только письменность и проверяются по хешу источника, а отдельные тесты сохраняют строки и строфы переводов.

03

Вёрстка и типографика

Редакционный CSS вместо компонентного фреймворка.

Вёрстка использует CSS Grid, subgrid, container queries, logical properties, custom properties и плавные размеры через clamp(). Media queries остаются консервативным запасным вариантом; при поддержке container queries модуль перестраивается по собственной доступной ширине.

Шрифты размещены локально в WOFF2. Основной латинский текст набран преимущественно EB Garamond, метаданные — Courier Prime и Cousine, традиционный китайский и японский — Shippori Mincho, упрощённый китайский — Noto Serif SC; редкие пробелы в гонконгских глифах закрывает крошечный subset I.Ming. CJK-подмножества пересобираются с fontTools и Brotli; источник Noto закреплён по commit и SHA-256.

04

Доступность

Настройка чтения без удаления содержания.

Используются семантические landmarks, один главный заголовок, skip links, заметный клавиатурный focus, полные названия языков и надёжные размеры сенсорных целей. Учитываются системные настройки reduced motion, повышенного контраста и forced colours.

Постоянная панель чтения позволяет включить шрифт без засечек, увеличить текст и интервалы, сузить строки, упростить раскладку, уменьшить движение и повысить контраст. Это progressive enhancement; настройки сохраняются только локально в браузере.

настройки
sans · larger type · spacing · measure · simple layout · motion · contrast
хранение
только localStorage
проверки
собственный структурный аудит · браузерный аудит axe-core

05

Изображения и производительность

Адаптивные медиа без runtime-галереи.

Фотографии и исследовательские иллюстрации используют picture/srcset с вариантами WebP и JPEG, явными размерами и responsive sizes. Главное изображение получает приоритет; медиа ниже по странице загружаются лениво и декодируются асинхронно.

Нижние разделы могут использовать content-visibility. View Transitions и scroll-linked motion остаются необязательными progressive enhancements; при reduced motion анимация отключается.

загрузка

content-visibility · View Transitions · scroll timelines

06

Сборка, QA и публикация

Сгенерированный результат тоже является объектом тестирования.

Репозиторий проверяет актуальность сгенерированных страниц, совпадение схем локалей, сохранность структуры литературных текстов, landmarks и элементы управления доступностью, локальные ссылки и fragments, alt text у изображений и синтаксис JavaScript.

Браузерный QA добавляет геометрические проверки для языков и узких/широких viewport, аудиты axe-core и HTML validation. GitHub Actions повторяет лёгкие проверки при push и pull request; GitHub Pages независимо публикует те же статические файлы из main.

07

Один домен, два типа страниц

Портфолио, литературные страницы, оболочки эссе, страница About и 404 используют описанную выше многоязычную систему генерации.

Три документа Cait Mail Assistant в /mail-assistant/ — это вручную написанный статический HTML с небольшой локальной таблицей стилей; они повторно используют локальный accessibility script портфолио и самостоятельно размещённые шрифты EB Garamond и Courier Prime.

Гид по холодильникам в /fridge/ намеренно сделан одним самодостаточным китайским HTML-файлом: inline CSS, системные CJK-шрифты и короткий JavaScript без зависимостей для размера текста, контраста и подсветки рекомендаций. Он не вызывает API и не загружает внешние CDN или analytics.

Приватность во время выполнения

Портфолио не загружает analytics, рекламные сети, сторонние web fonts или tracking scripts и не устанавливает cookies. Единственное постоянное состояние браузера — локальная запись настроек чтения.
