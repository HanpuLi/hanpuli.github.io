À propos du site

Ce site est volontairement statique. Les pages publiques sont d’abord des documents complets : HTML, CSS et ressources locales portent le contenu ; un peu de JavaScript natif n’intervient que lorsque l’interaction apporte réellement quelque chose.

La règle est simple : le contenu doit rester lisible sans framework, sans couche de traduction côté client et sans rendu piloté par JavaScript.

01

Architecture

Statique par choix.

Le portfolio est généré sous forme de documents HTML5 complets à partir de petits templates et de JSON structuré. Un générateur fondé sur la bibliothèque standard de Python 3 produit chaque version linguistique à l’avance ; le navigateur n’assemble pas le site à l’exécution.

Le site est servi par GitHub Pages depuis la branche main. Le portfolio n’a derrière lui ni CMS, ni framework applicatif, ni base de données, ni application côté serveur.

HTML5 · CSS · JavaScript natif
build

02

Contenu & langues

Sept éditions, aucune traduction à l’exécution.

L’anglais, le chinois traditionnel de Hong Kong, le chinois simplifié, le japonais, l’allemand, le français et le russe sont générés comme éditions statiques distinctes, avec URL canonical, alternates hreflang et métadonnées propres à chaque langue.

Les textes littéraires suivent des règles plus strictes que les libellés d’interface. Quand cela est défini, le chinois traditionnel fait foi ; les miroirs littéraires simplifiés ne changent que l’écriture et sont contrôlés par hash de source, tandis que des tests dédiés conservent lignes et strophes des traductions.

03

Mise en page & typographie

Du CSS éditorial plutôt qu’un framework de composants.

La mise en page utilise CSS Grid, subgrid, container queries, logical properties, custom properties et des dimensions fluides via clamp(). Les media queries restent des solutions de repli prudentes ; quand les container queries sont disponibles, chaque module se réorganise selon sa propre largeur.

Les polices sont auto-hébergées en WOFF2. EB Garamond sert principalement au texte latin, Courier Prime et Cousine aux métadonnées, Shippori Mincho au chinois traditionnel et au japonais, Noto Serif SC au chinois simplifié ; un minuscule sous-ensemble I.Ming complète les rares glyphes hongkongais manquants. Les sous-ensembles CJK sont reconstruits avec fontTools et Brotli ; la source Noto est épinglée par commit et SHA-256.

04

Accessibilité

Adapter la lecture sans retirer de contenu.

La structure repose sur des landmarks sémantiques, un titre principal, des skip links, un focus clavier visible, des noms de langue complets et des cibles tactiles fiables. Les préférences système reduced motion, contraste renforcé et forced colours sont respectées.

Un panneau de lecture persistant peut activer une police sans sérif, agrandir le texte, augmenter les espacements, raccourcir les lignes, simplifier la mise en page, réduire le mouvement et augmenter le contraste. Tout cela reste du progressive enhancement et les réglages sont stockés uniquement dans le navigateur.

audit structurel maison · audit navigateur axe-core

05

Images & performance

Médias responsives, sans runtime de galerie.

Les photographies et planches de recherche utilisent picture/srcset avec variantes WebP et JPEG, dimensions explicites et responsive sizes. L’image d’ouverture est prioritaire ; les médias plus bas dans la page sont chargés en lazy-loading et décodés de façon asynchrone.

Les sections sous la ligne de flottaison peuvent utiliser content-visibility. View Transitions et scroll-linked motion restent des progressive enhancements facultatifs ; reduced motion désactive les animations.

images
picture · srcset · WebP · JPEG
chargement
explicit dimensions · lazy loading · async decoding
CSS progressif
content-visibility · View Transitions · scroll timelines

06

Build, QA & déploiement

Le résultat généré est lui-même testé.

Le dépôt vérifie que les pages générées sont à jour, que les schémas de locale concordent, que la structure des textes littéraires n’a pas dérivé, que landmarks et contrôles d’accessibilité restent intacts, que liens et fragments locaux se résolvent, que les images ont un alt text et que le JavaScript se parse.

La QA navigateur ajoute des contrôles géométriques entre langues et viewports étroits/larges, des audits axe-core et une validation HTML. GitHub Actions répète les contrôles légers lors des push et pull requests ; GitHub Pages publie indépendamment les mêmes fichiers statiques depuis main.

07

Un domaine, deux types de pages

Le portfolio, les pages littéraires, les enveloppes d’essai, la page About et les pages 404 partagent le système multilingue généré ci-dessus.

Les trois documents Cait Mail Assistant sous /mail-assistant/ sont du HTML statique écrit à la main avec une petite feuille CSS locale ; ils réutilisent le script d’accessibilité local du portfolio ainsi que les polices EB Garamond et Courier Prime auto-hébergées.

Le guide des réfrigérateurs sous /fridge/ est volontairement un seul fichier HTML chinois autonome : CSS inline, polices CJK système et un court JavaScript sans dépendance pour la taille du texte, le contraste et la mise en évidence des recommandations. Il n’appelle aucune API et ne charge ni CDN externe ni analytics.

Vie privée à l’exécution

Le portfolio ne charge ni analytics, ni réseau publicitaire, ni web font tierce, ni script de suivi, et ne dépose aucun cookie. Le seul état persistant du navigateur est l’enregistrement local des préférences de lecture.
