## C. 本轮具体实修，前后对照

以下改动已写入 `content/poetry/kunten-manuscripts.json` 并同步生成 `content/poetry/kunten.json` 的相应 marks 数组；仅改变相应字位，不重写他处中文原文。源中文及作品版本无更改。

1. **甲四「孤燈紅淚共商量」**：書き下し「孤灯の紅涙、共に商量す」→「孤灯の紅涙のもと、共に商量す」。小字 `紅淚共` → `紅淚{ノモト}共`。把红泪还原为灯下景象，不把灯泪误作商量者；「のもと」是明示的编辑补读。
2. **甲九「箋中淺字只加餐」**：`加[レ]餐{ヲ}` → `加(くわ){ヘヨト}[レ]餐{ヲ}`。反读「餐ヲ→加ヘヨト」；补足独立書き下し「餐を加えよと」的引用命令语势，而非平铺为一般叙述。
3. **甲十「認不真，卻認真」**：書き下し「判然と認め得ず、却って真剣なり」→「判然と認め得ず、却って真剣に向き合ふ」。保留两种现代汉语义项的词性与动作差别；原短语仍不置伪返点。
4. **乙六「稚女描新帖」**：`描(なぞ){リテ}[二]` → `描(なぞ){リ}[二]`，去除与书面「新帖をなぞり」不符的额外接续。
5. **乙六「擱筆無可酬」**：`無[二]可[レ]酬{フ}[一]` → `無{シ}[二]可{ベキ}[レ]酬{フ}[一]`。试读「酬フ→可ベキ→無シ」以对应「酬うべき無し」，不改成无字可说。
6. **乙七「夜深方得眠」**：`得[レ]眠{ル}` → `得[レ]眠{ルヲ}`，试读「眠ルヲ→得」对应「眠るを得」。
7. **乙七「忘川人自渡」**：`忘川{ヲ}人{ハ}自{ラ}渡{リ}` → `忘川{ヲ}人自{ラ}渡{リ}`，去掉书き下し未有的主题助词；不给义务情态。
8. **《風入松》「已凝霜，依舊頑陽」**：`已{ニ}凝[レ]霜{ヲ}，依[レ]舊{ニ}頑陽` → `已{ニ}凝{リ}[レ]霜，依{リテ}[レ]舊{ニ}頑(かたくな){リ}[レ]陽{ハ}`；霜的凝结不改为对霜施行动作；頑なり按ナリ活用。
9. **《風入松》「斜暉落甓猶難去」**：`斜暉落[レ]甓{ニ}猶{ホ}難[レ]去{リ}` → `斜暉{ハ}落{チテ}[レ]甓{ニ}猶{ホ}難{ク}[レ]去{リ}`；「去り難く」为复合述语，保留「猶」。
10. **《風入松》「然金爐、待子宵長」**：`然(も){ヤシ}[二]金爐{ヲ}[一]、待[二]子{ヲ}[一]` → `然(おこ){シ}[二]金爐{ニ}[一]、待{チテ}[二]子{ヲ}[一]`；从焚烧炉体改为在炉中起火的作者语境义训，「火」不是中文原字，应在读者注释说明。
11. **《風入松》「千里行來至此」**：`千里行{キ}來{タリテ}至[レ]此{ニ}` → `千里{ヲ}行{キ}來{タリテ}至{リ}[レ]此{ニ}`，补行程的对象及与「此」对应之述语。
12. **《風入松》「雁丘今可成堂」**：`可[レ]成[レ]堂{ヲ}` → `可(べ){シ}[レ]成{ル}[レ]堂{ト}`；書き下し「雁丘は今堂を成すべし」→「雁丘は今堂と成るべし」。将「成堂」读作状态成为，不增加建堂施事；「べし」采用可能／推测义，不能读成必然完成或命令。
13. **《風入松》「化紙」**：`化(や){キ}[レ]紙{ヲ}` → `化(た){キテ}[レ]紙{ヲ}`，调整到「紙を焚きて」，保存焚化意象。
14. **《風入松》「料經年、應易遷忘」**：`經[レ]年{ヲ}、應…易[レ]遷忘{シ}` → `經{レバ}[レ]年{ヲ}、應…易{カル}[レ]遷忘{シ}`，条件与ク活用一致，料的揣度不移除。
15. **《滿庭芳》「指過眉山」**：`指過[二]眉山{ヲ}[一]` → `指{ハ}過{グ}[二]眉山{ヲ}[一]`。眉山作为眉部意象的受事，不是城市；不指定指的主人。
16. **《滿江紅·重讀舊作》「言可續，時難逆」**：`言可[レ]續{ギ}，時難[レ]逆{ニス}` → `言{ハ}可(う)[レ]續{ギ}，時{ハ}難{シ}[レ]逆{ニシ}`，以「継ぎ得」「逆にし難し」作编辑义训，保存两者可能性与难度的不对称；可(う)的训非经辞典证实的“可”的固有训。
17. **同首「字入年輪方有響」**：`字入[二]年輪{ニ}[一]方…有[レ]響{キ}` → `字{ハ}入{リテ}[二]年輪{ニ}[一]方…有{リ}[レ]響{キ}`；「字が年輪に入る→初めて響きあり」，入是有响的条件。
18. **同首「痕藏木理猶能識」**：`痕藏[二]木理{ニ}[一]猶{ホ}能[レ]識{ル}` → `痕{ハ}藏{レテ}[二]木理{ニ}[一]猶{ホ}能(う)[レ]識{リ}`，保存木理中藏痕及仍可辨认。

### 返读最小推演与失败边界

- 甲三「未敢喚真真」：词组结构 `未〔敢〔喚〔真真〕〕〕`，从 `真真` 整组读至 `喚`，再接 `敢`、`未`。仅将「喚レ真」逆置相邻一个汉字会将专名拆散。
