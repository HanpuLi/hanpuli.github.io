# 漢文訓点・書き下し文校勘台账

2026-10-13。工作分支：feat/kanbun-betagumi-20261013。原件为 content/poetry/library.json 中的繁体中文诗词，作者解释见 content/poetry/translation-guidance.md。日语書き下し文存于 content/poetry/kundoku.json，逐字训点数据存于 content/poetry/kunten.json。

## 已做的校勘

共32份古典文本，现已全部补齐原文字位绑定的训点实验稿。状态 `pilot-reviewed` 表示已有人工编辑、可用机器复核原文及排版的实验性读法，**不是经过日本汉文学同行认可的定本**。现代白话构词及作者特定义训没有强行编造历史训法。

本次新增乙二、甲五、甲八、2018年《臨江仙》、甲九、甲二、五段乙六、《應天長》，共8份。上一次迭代增加乙七、《朝中措》、甲四、甲三、甲一、乙一、甲七，并保留最早的乙五试点。

实校取舍：

- 乙二「歡猶未省」按思念之人尚未察觉，不以「欲喚還休」推出停止呼唤的原因。「欲先寒」保留即将发冷的语势。
- 甲五「那夜誰分賓主」为疑问，不指定双方是否同样理解当晚；「雪泥誰去早」未辨明谁先走。「不曾瞞」否定当晚隐瞒，不填入具体言辞。
- 甲八「昔我今何在」保留前后的同一人称与时间变化。「側耳疑相答」仅称疑有回应，不将两人对话确认为事实。
- 2018年《臨江仙》「炭冰摧過後」中炭和冰是造成伤害的力量，不是自己粉碎。其他景象及所涉典故分开处理，未编造成单一乐曲。
- 甲九「賓一哂，語猶慳」不固定寡言者是谁。「加餐／怕誤／欲喚還休」来自另一些版本的话语，由甲的叙述重新编排，不证明乙的意图。「留得」的得是结果补语，不假装是传统置字。
- 甲二「沈醉曾扶」不决定谁扶谁。「當筵曾許心期」不升级成终生誓言。「朝霞渾未記」作未被记录，不把朝霞写成施事。
- 乙六五段16行全部逐字回核。「春痕」含春时与痕迹；「稚女描新帖」是照新字帖临摹；「指印」不是特意盖章；「無可酬」不等于没有文字；「我亦有天涯」不等于已经忘掉对方。「所憑」是关系性名词结构，仍需专门确认是否最佳日语返读。
- 《應天長》「空衣」没有穿衣者；「匙底」为勺底；「殘齒」可能残存也可能残缺，不指定牙齿主人；最后五元素只作原列记。「聽盡」作为双字动词，针对「無聲」整组的返点属于编辑用法，不能冒充既定古典示例。
- 乙七「忘川人自渡」已从「忘川は人自ら渡り」校作「忘川を人自ら渡り」，保持各自渡过而非道德命令。
- 九月九日《臨江仙》原書き下し的「月上りて夜将に残らんとす」误让读者理解夜将继续存留，已校为「月上りて夜は将に尽きんとす」。此处尚未制作逐字训点，避免给「殘」生造传统读法。

## 后续13份的语义校勘与未决问题

以下作品已补齐逐字附训稿。保留的说明是语义／训读仍须由日语汉文学专家复核的边界，不再表示文本尚未进入阅读器。

1. 乙三：不是东风先折取与恐花为我辞根是两层否定、恐惧和省略施事；「得」与「未緘」须分开。
2. 乙四：「緘淺」的双关及「別處温言」的指代不能强制确定；「一諾窮年」是将来可能的解读。
3. 甲六：「鏽暗生」在日语中存在名词与后置形容关系；「避却鴛鴦字」需要多字目的语的层级返读。
4. 甲十：现代汉语「認不真／認真」双关不应全篇硬套历史汉文训点；拟另设现代汉文日语读法。
5. 《鷓鴣天》：「蘸得毫端黑」的得是结果补语，不得假借传统置字名义。
6. 九月九日《臨江仙》：「重簾」的重读为沉重；「夜將殘」须保持夜将尽的语义；「垂到地／垂來」复合方向动词需定注。
7. 《臨江仙引》：「礄」的石质道路义来自作者用字语境，不能声称字典以「いし」为标准训。
8. 《風入松》：「然金爐／化紙」的焚化链及「料」的推测性要共存，不能淡化雁丘与死亡联想。
9. 《滿庭芳》：「辭顏」是人名；「墨跡」为后文欲出行间的主语，不能视作已经逸出纸面。
10. 《滿江紅》缝补稿：「初景寒柯違業識」含并列对照与典故，须先验证关系和双重目的语。
11. 《滿江紅》回声稿：「曉山塗」现代日译取山阻塞；「豐城元禮」不凭邻接自动断定历史人物关系。
12. 《滿江紅》重读稿：多重转折和时间不可逆需要确认完整返读层级。
13. 《鵲橋仙》：作者将「未消尺素」解释为不需要书信，不能按「尚未消逝」字面重新翻译；该句不宜机械制造返点。

## 本轮再校（甲六、乙三的返读层级）

- **甲六「相看似隔前生事」**：原试稿把「似」注作「テ」，没有给整段「前生事 → 隔 → 似」的返读顺序。现标为「似三／隔二／事一」，保留《書き下し》「前生の事を隔つるに似て」的顺序。这是编辑訓，不声称历史传本已有此训点。
- **乙三「恐花為我辭根」**：原来「恐二／辭レ／根一」未明确显示两个谓语层级。现为「恐三／為レ我／辭二／根一」，表示「花、我が為に、根を辞するを恐る」。不由此确定花被谁折取。
- **2026-10-15 返点改为高校教科书规范（读序不变）**：相邻一字返读用レ点，二一不相邻；一二点套一二点时外层用上下点；上下点只用在包着一二点时。乙三改「恐二／為レ我／辭一レ根」（字序 花→我→為→根→辭→恐）。甲五小序「記二醉後…始無一レ避焉」（原上下点内无一二点）。甲九小序「得二某所レ寄舊稿一」「與二篋中所一レ存」（原「所二寄一」「所二存一」为相邻一字返读）。这三条规则已写进 `tools/poetry_kunten.py` 的 `check_marks`，正文与标题都校。全库无甲乙点、天地人点：诗句短，最多到上下点一层。
- **现代汉语专用结构**：撤掉乙三「不是」上的两个机械レ点、甲六「把」上的一二点。两者不能因为网页希望呈现完整小字就伪作教科书式古汉文训法，释义仍交由已经校订的書き下し文。
- **甲六的词组边界**：在「痴根」的「根」旁标明宾语「ヲ」，避免把「痴根草」误合为一物。但「齧盡」作为复合结果动词尚未用单字返点充分表达，继续列为义训问题，不宣称校勘完成。
- 编译检查现在逐字固定这两组三／二／一定位，保护「不是」「把」免遭后续自动加点，并验证痴根与草的分界。所有新标记仍按中文正典 SHA-256 锚定。
- **双字宾语返读**：《滿江紅·縫補稿》的「縫新隙」「須揀擇」「看收場」，以及《滿庭芳》的「過眉山」，原稿用了「レ」来读后面双字宾语，实际只能回读一字。四处均改成「首字二／末字一」，并为每处添加原文字位的回归断言，防止今后自动排版掩盖返读范围错误。
- **《鷓鴣天》「蘸得毫端黑」**：原标注「蘸して得テ」重复生成了書き下し文所没有的「テ」。按「得」是现代汉语结果补语的句法说明，撤掉这个独立送假名，仅保留原汉字及语法注。已为该字位增加专项编译断言；此决定是编辑性训读取舍，不声称结果补语等于古汉文置字。


## 排版与原件核验

每份添加的训点都以原文 SHA-256 和零起点 Unicode 字位锚定；剥除训点后必须逐字恢复原文的字、标点、换行和段落。上游 kanbunHTML 密排引擎负责字格，站点布局负责在手机端仅按作者的完整诗行换带，保留上下阕。日本页面可切白文、复制纯中文原文，无脚本时也读取原文。

当前浏览器覆盖 Chromium 和 WebKit 的320、390、1280px，29份试点文本共174个作品／视口组合；碰撞检查使用汉字与小字的实际矩形，不只凭页面无横向滚动作为通过凭据。乙六五段的200%文字放大及反复重排另设专项回归，确认不会裁掉诗尾；甲十现有保留现代义训的训点试排稿，切换至白文后应回到完整分带且不出现65px横向溢出。
