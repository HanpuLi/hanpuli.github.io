## 不以配对测试代替真实返读

`/Users/caitlye/Desktop/_Code/hanpuli-kanbun-betagumi-20261013/tools/poetry_kunten_manuscript.py` 增加了独立的基本返读顺序模拟。通过逐字索引推演，不从当前书き下し直接反向复制答案。已覆盖：

- 甲三「未敢喚真真」：真真 → 喚 → 敢 → 未。
- 甲四「逢人怕説西窗」：人 → 逢 → 西窗 → 説 → 怕。
- 甲六「似隔前生事」：前生事 → 隔 → 似。
- 乙三「恐花為我辭根」：花 → 我 → 為 → 根 → 辭 → 恐。
- 乙六「失所憑」：憑 → 所 → 失。
- 乙六「非是無一字」：是 → 一字 → 無 → 非。
- 《滿江紅》两版「初景寒柯違業識」：初景 → 寒柯 → 業識 → 違。
- 《朝中措》「作，銀磬微鳴」：银磬微鸣 → 作，读点不作为语法绝对边界。

这个函数是选定片句的字序追踪器，不是可全面自动证明汉文训读合法性的专家系统。复合动词、结果补语和作者现代用语仍需要人工作特殊处理。
